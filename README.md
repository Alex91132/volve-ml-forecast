# Volve ML: прогноз дебита нефти на месяц вперёд

Второй проект трилогии по данным месторождения **Volve** (Equinor, Северное море).
Задача: предсказать среднесуточный дебит нефти скважины в следующем месяце по
истории её работы и состоянию поля.

## Чем отличается от «ноутбука с ML»

1. **Честная валидация**: бэктестинг раскрывающимся окном по времени — модель
   обучается только на прошлом и предсказывает следующий месяц. Никакого
   случайного train_test_split (он подмешивает будущее в прошлое).
2. **Бейзлайны, которые не стыдно показать**: наивное «как в прошлом месяце» и
   экстраполяция экспоненциального падения. ML обязан их обыграть.
3. **Чувствительность к выбору шкалы**: без логарифмирования целевой переменной
   бустинг *проигрывает* бейзлайнам (MAE 121 против 115) — большие скважины
   монополизируют квадратичную потерю. Обучение на log1p(дебита) меняет
   картину: ошибка становится относительной.
4. **Разбор ошибок**: где модель выигрывает (спокойные месяцы) и где нет
   (переходные режимы), важность признаков (permutation importance).

## Результаты (6 срезов бэктестинга, 2015–2016)

| Модель | MAE, м³/сут | Улучшение vs наивного |
|---|---|---|
| Наивный (прошлый месяц) | 115 | — |
| Экспоненциальный decline | 118 | −3 % |
| **Градиентный бустинг (log-таргет)** | **64** | **44 %** |

По скважинам эффект неоднороден: 4 из 5 скважин ML лучше бейзлайнов. Главные
признаки — свежая история дебита самой скважины (лаги, скользящие средние);
технологические параметры (давление, штурвал, наработка) и закачка поля —
второй эшелон.

## Признаки (только из прошлого)

Лаги дебита 1–3 мес, скользящие 3/6 мес, дебит жидкости и обводнённость,
наработка и штурвал (лаг + скользящее), забойное и устьевое давление,
накопленная добыча, возраст скважины, закачка по полю с лагом 1 мес,
идентификатор скважины (категориальный).

## Структура и запуск

```
├── volve_ml_forecast.ipynb   # основной ноутбук (исполнен)
├── analysis.py               # исходник в формате jupytext-ячеек (# %%)
├── make_notebook.py          # сборка analysis.py -> ipynb
├── data/daily.csv            # суточная добыча Volve (15 634 строки)
└── requirements.txt
```

```bash
pip install -r requirements.txt
python make_notebook.py && jupyter nbconvert --to notebook --execute --inplace volve_ml_forecast.ipynb
```
